Данный проект представляет собой одностраничный сайт (SPA) для кафе «Crumble Cafe», разработанный с использованием сборщика Webpack. Главная особенность проекта — переключение между вкладками («Главная», «Меню», «Контакты») происходит динамически, без перезагрузки страницы.

В ходе работы были выполнены все три уровня заданий. В рамках базового уровня была добавлена третья вкладка «Контакты» с выводом адреса, телефона, часов работы и ссылки на соцсеть, а также реализовано визуальное выделение активной вкладки через класс .active. Вся стилизация вынесена в отдельный CSS-файл: настроены фоновый цвет, hover-эффекты для кнопок навигации и подключен нестандартный шрифт (Pacifico) через Google Fonts.

На втором уровне данные для меню были вынесены из кода в отдельный файл menu-data.json, а генерация карточек блюд теперь происходит через цикл forEach. В проект добавлены изображения блюд, для корректной работы которых в webpack.config.js были настроены asset modules (правило для обработки картинок). Также на вкладке «Контакты» появилась кнопка «Забронировать столик», вызывающая всплывающее окно (alert) при клике.

На третьем уровне была реализована форма обратной связи с полноценной валидацией полей: имя должно содержать минимум 2 символа, а email проверяется через регулярное выражение. При ошибках ввода поля подсвечиваются красным и выводятся сообщения, а при успешной отправке данные очищаются. Кроме того, с помощью localStorage реализован счётчик посещений вкладки «Меню» (он сохраняется даже после перезагрузки страницы), а переключение вкладок сопровождается плавной CSS-анимацией fadeIn.
